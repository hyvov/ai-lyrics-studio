# AI Lyrics Studio

AI 唱歌改词工具：导入歌曲、编辑歌词，沿用原曲旋律生成演唱，再与伴奏混合导出。

## 当前状态

项目初始化阶段，尚未实现可运行应用。

## 首版目标

1. 导入本地歌曲，分离人声与伴奏。
2. 识别原歌词，建立逐句与逐字时间轴。
3. 编辑歌词，检查字数、发音与音符时长的适配。
4. 按句生成新演唱，支持试听和重新生成。
5. 混合伴奏，导出音频及带时间戳的歌词。

## 目录

- `backend/`：音频处理、项目管理与模型适配。
- `frontend/`：歌词编辑、时间轴与试听界面。
- `docs/`：设计与开发计划。

模型权重、音频素材、运行时环境和密钥不提交到仓库。第三方组件需核对许可证及使用条件后再引入。

## 开发方向

优先考虑本地运行：Python 后端、独立模型适配层、支持时间轴编辑的前端。
详细范围见 [首版设计](docs/mvp.md)。
