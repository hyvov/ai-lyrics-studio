# SRT / LRC 字幕使用说明

## 导入

先导入原唱或干声，再点击“导入 SRT / LRC”。选择 `.srt` 可直接读取字幕，不需要转换格式。支持 UTF-8、带 BOM 的 UTF-16 和常见 GBK/GB18030 编码，单文件最大 2 MB。

标准 SRT 示例：

```srt
1
00:00:01,234 --> 00:00:02,345
第一句歌词

2
00:00:05,000 --> 00:00:07,001
第二句歌词
```

导入后第一句仍是 1.234–2.345 秒，第二句仍是 5.000–7.001 秒。保留句间空隙，最后一句不会延长到音频末尾。

多行字幕合为同一句。去除常见 b/i/u/font/span 样式和 ASS 位置标记；保留歌词文字。双语字幕会将各行合并，若音频只唱一种语言，应先删除翻译行，使原词与实际演唱一致。

对时间倒置、重叠、超出音频、时间格式错误或空字幕，显示具体错误，原有歌词不变。再次导入会替换整个工程的歌词编辑，操作前有确认。

## 编辑与导出

“改词”弹窗显示 SRT 的实际起止时间，可按毫秒微调。字幕导入可包含短片段，当前模型生成要求单句 0.12–20 秒、新旧发音单位数量一致；不足 1 秒时需要重点试听。

顶部选择 SRT 或 LRC，点击“↓ 歌词”下载。SRT 导出保留当前编辑后的起止时间和歌词；LRC 只表达起点，重新导入时会以相邻起点推算结束时间。

## 测试音与真实演唱

“功能验收 · 合成测试音”中的 test-tone.wav 是程序测试音，不包含唱词。改变一个字也不能使其具有可对齐的演唱。界面会持续标注、禁用生成，后端在加载模型前拦截已知测试文件。此识别按文件内容，而非文件名，不是通用的人声检测器。

处理自己的歌曲时，选择实际原唱干声，并导入对应的 SRT；要试用生成，可切换到已有的演唱示例。
