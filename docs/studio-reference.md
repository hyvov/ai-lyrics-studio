# 本地 SoulX Studio 优化实现参考

本项目后续以本机 `%LOCALAPPDATA%/SoulX Studio` 的实际工作流为主要参考。这里记录已核对的实现语义与本工具对应改进，避免把上游原始推理脚本当作完整产品。

| 本地参考 | 实现要点 | 本工具对应改进 |
| --- | --- | --- |
| backend/models.py 的 Segment.unit_timings | 每个字词有实际起止时间 | 对齐结果持久化；主歌词点击按实际字词定位 |
| backend/service.py 的 correct_original_lyrics | 区分原唱识词校正和改词 | 原词校正接口；保留用户已经修改的新歌词 |
| backend/service.py 的 update_timeline_segment | 保存时间轴并处理过期产物 | 逐字数值微调、范围/重叠校验、生成指纹失效 |
| backend/models.py 的逐字时间请求结构 | 时间轴是可编辑数据而非显示估算 | 独立时间轴编辑器、逐字试听和时间保存 |
| backend/timeline_analysis.py 与对齐组件 | 先分析再供编辑/生成使用 | 独立对齐任务；不必先合成整句才能获得时间 |

## 当前使用方式

打开顶部“歌词时间轴”，左侧选句：

1. 校正“原唱实际唱词”，保存；已改过的新歌词不会被覆盖。
2. 点击“提取当前句逐字时间”。模型任务只做对齐，不加载演唱模型。
3. 点击文字试听，修改每字/词的起点和终点，保存。
4. 回到改词/生成界面。后续生成复用已保存时间，并在日志记录 alignment_cached。

主歌词按中文汉字、完整英文单词建立按钮，保留原有空格和标点。可用逐字时间时按真实时间定位并高亮；缺少时间时明确标为估算。

## 数据一致性

对齐缓存取决于原始音频、原词和句子边界，新歌词变化不必重复对齐。原词或句子边界改变后自动失效。手动时间参与生成指纹，旧音频会变为过期。模型任务中途发生新的手动修改时，旧结果不能覆盖手动数据。

手动值以秒保存、输入步长 1ms，每个字词至少 20ms。模型内部按声学帧工作，输入毫秒精度不等于毫秒级声学精度。重新提取时间会使当前句已有音频过期，界面会先确认。

## 验证与边界

已用实际唱句完成“独立提取 13 字时间 → 手动修改 → 保存 → 复用时间生成”的完整验证。单元测试还覆盖原词校正不丢改词、缓存失效、时间重叠、旧任务结果拒绝覆盖。

当前提供数值编辑，尚未实现波形拖拽、相邻句边界联动、MIDI 钢琴卷帘和跨发音单位数量的改词适配。这里的参考不代表已完整复现 SoulX Studio 的所有优化。安装目录中的商业后端没有复制到仓库，接口与数据规则由本项目实现。
