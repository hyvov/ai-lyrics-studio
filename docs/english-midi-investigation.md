# 英文 MIDI 音素控制调查

目前 StudioDataProcessor 将每个音符的英文音素展开为 token。对于音符内多个音素，它在 mel2note 中循环分配 token，例如 R、EH、R、EH，而不是连续的 R 区间和 EH 区间。模型在 MIDI 模式用该映射扩展音符特征；音素逐帧输入不等于模型承诺逐帧声学对齐。因此仅给界面增加音素拖拽不能宣称控制真实发音。

现有可控制的是音符边界和每个音符分配的音素组，以及相邻空档借用。下一步应保留现有行为作为对照，实验性构造连续音素映射，验证训练时映射分布与推理结果；用相同参考、音符、种子和参数生成对照，检查时长、音频波形和实际听感。只有验证通过才能作为可编辑功能交付，避免破坏现有生成。

案例：分开的时候 → rest的时候。目标把 R/EH/S/T 保留在前段，的放入原静音区，时候保持原边界；原词片段必须遮罩，避免泄漏原唱。
