# 首版设计

## 用户流程

创建项目 → 导入歌曲 → 人声分离 → 歌词识别与对齐 → 编辑歌词 → 分句生成与试听 → 混音导出。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| 项目管理 | 保存素材引用、歌词、时间轴、生成参数和任务状态 |
| 人声分离 | 将输入音频拆分为人声和伴奏 |
| 识别与对齐 | 识别歌词，将字词映射到时间位置，允许人工校正 |
| 旋律分析 | 提取音高、音符及持续时间 |
| 歌词适配 | 检查新歌词与原有节奏的匹配，提供人工调整入口 |
| 演唱生成 | 接收参考音频、歌词及旋律条件，生成目标片段 |
| 混音导出 | 拼接片段、调节音量并导出音频和歌词 |

## 技术选择

- 后端候选：Python + FastAPI。
- 模型通过独立适配层接入，模型下载与应用代码分离。
- 演唱模型候选：SoulX-Singer；引入前核对上游来源、许可证、推理接口及显存需求。
- 识别、对齐和分离方案以实际歌曲片段验证后确定。
- 前端框架与桌面打包方式在核心生成流程验证后确定。

## 验收目标

使用有权处理的一小段歌曲，完成导入、改词、生成、试听及混音导出。核对新歌词是否清晰、节奏是否对齐，以及片段拼接是否产生明显断音。
