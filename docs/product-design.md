# 产品与交互设计

## 设计依据

按用户要求，参照本机 SoulX Studio 的实际主界面和“修改歌词并确认边界”弹窗设计。2026-11-03 已通过运行中的应用观察这两个视图。取代此前深色三栏编辑器方向。

## 主界面

- 暖白背景、珊瑚橙强调色，可切换夜间主题。
- 顶部：应用与工程名称、引擎状态、MV 工作台、歌词时间轴、导出、设置。
- 左侧：我的工程、创建工程、工程列表及句数与生成状态。
- 中间：整首歌词、改词与完成数量、重新提取入口。歌词居中逐句展示，突出当前句，每句提供改词按钮。点击歌词字定位时间。
- 底部：播放、人声与伴奏双轨、轨道开关、原唱/改词/SVC 切换、音色转换与待生成句数。
- 狭窄预览面板隐藏工程侧栏和次要工具，优先保留歌词、改词入口和播放区域。

## 改词弹窗

1. 显示当前句序号及时间范围。
2. 提供旋律/MIDI 生成方式与原句音色选项。
3. 显示原人声波形、起止边界、试听入口和整首概览。
4. 对照原唱实际唱词，编辑新歌词并保留停顿标记。
5. 显示新歌词槽位分配、匹配提示和异常状态。
6. 确认保存或重新生成当前句。

真实实现需要校正原词、真实音符/音素槽位与拖动波形边界。数值与滑块用于调整实际句子边界，已接入原唱音频解码波形，当前句波形随起止边界裁切。字数相同仅是显示提示，不代表已经完成旋律适配。

## 编辑与生成规则

- 编辑文本、边界、生成方式、参考音色条件后，使相应产物过期。
- 真实任务完成时比较输入版本，避免旧结果覆盖新编辑。
- 批量生成处理已修改且没有有效产物的句子。
- 原始素材只读；真实应用需自动保存、撤销、恢复项目和保存历史生成。
- 缺模型、显存不足、对齐异常等错误保留已完成产物，并提供对应重试操作。

## 当前实现与限制

通过 `python -m backend.app` 启动本机服务，再打开 http://127.0.0.1:18733 。`design/` 提供运行界面。

已接入工程磁盘存储、原唱与伴奏音频上传、真实解码波形、双轨同步试听、句子边界编辑、SRT/LRC 时间轴导入和导出。工程更新使用版本号，防止多个页面静默覆盖。

SRT/LRC 提供句子边界，界面逐字定位暂按字数估算；生成任务会执行实际强制对齐、音高和音符分析。文字格仅供参考。已接入真实演唱与混音导出，分离、自动识词、SVC 与 MV 仍待实现。

实际句子数据保存到本机，源文件不被覆盖。再次导入 SRT/LRC 会替换当前歌词编辑，需要确认。尚未提供撤销、历史版本选择界面或波形边界直接拖拽；生成产物和对齐元数据已保存在本机。

使用自写界面代码，不包含 SoulX Studio 品牌素材或商业应用源码。

## 验收

界面：核对主界面和改词弹窗的桌面布局、窄屏适配、编辑保存、边界校验和产物过期。
音频：另行使用 20–30 秒素材验证改词、生成、原新对比、重新生成及混音导出，检查吐字、旋律、节奏、接缝和伴奏同步。

已通过浏览器使用 12 秒合成测试音验证创建工程、音频与 LRC 导入、改词保存、刷新恢复、双轨播放进度和 LRC 下载。已测试桌面与窄面板布局。另已完成官方片段的真实 GPU 改词生成、改词轨与导出验证，音频听感需人工试听。

## 已接入真实演唱

主界面显示共用模型状态；生成弹窗可直接保存并启动当前句生成，底部按钮批量处理待生成句。生成时显示对齐、音高、音符、模型加载、演唱与拼接阶段，支持取消。完成后可切换改词轨，原唱/改词切换保留时间位置，并导出演唱与混音 WAV。

首版要求同发音单位数量，停顿沿用原句。实际音素/音符适配在后台执行，当前弹窗的文字格仍是编辑参考。原句音色转换选项禁用，SVC、MV 和自动提取入口明确标为尚未实现。


## 字幕入口与误用防止

“导入 SRT / LRC”支持原生字幕，SRT 使用显式起止时间，不借用下一条字幕作为结束时间。顶部导出格式默认为 SRT，可切换 LRC。导入失败不覆盖现有编辑。

按实际文件内容识别旧版合成测试音；项目列表和工作区持续提示“无演唱，不可生成”，保留编辑与播放能力，但不启动 GPU。可从提示切换到已有有效生成产物的演唱工程。
