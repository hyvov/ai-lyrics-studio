# 产品与交互设计

## 定位与范围

面向需要为现有歌曲替换歌词的创作者。首版围绕本地素材、逐句修改、保持旋律条件、试听比较与混音导出展开。生成质量必须实际验证，不承诺完全复刻原唱。

探索了三种组织方式：多轨录音台适合精细混音但学习成本较高；逐句编辑器直接对应改词任务；步骤向导容易上手但来回修改繁琐。首版采用逐句编辑器，时间轴作为辅助。

## 视觉 brief

安静、精确的录音室工作台。深墨色背景，暖白歌词，珊瑚橙只突出选中句与生成操作。中文使用系统字体，时间与状态采用等宽字体。顶栏放项目与导出，中间主区编辑句子，右侧调整当前句，底部播放与时间轴。避免大面积宣传文案、装饰性仪表盘和无意义统计。

## 主操作

1. 新建项目：选音频，可同时导入已有干声、伴奏或 LRC。已有分轨可跳过分离。
2. 分析素材：分离、识别、对齐、旋律提取各自显示任务状态。失败后保留已完成产物并允许重试。
3. 校对原词：先允许修正识别错误和边界，再编辑目标歌词。修正原词会使相关对齐结果失效。
4. 改词：每句显示起止时间、原词、新词和状态。选中句显示字数差异；以音节、时长和音符关系判断适配，字数相同仅是提示。
5. 生成：默认仅生成选中句；批量生成只处理已修改且没有有效产物的句子。
6. 试听：原唱与新唱在同一片段位置切换，支持循环与伴奏音量。保留历史生成版本以便回退。
7. 导出：可导出完整混音、生成干声和歌词。尚有未生成的修改句时明确提示并阻止误导性的完整导出；用户可选择仅导出已完成片段。

## 编辑规则

- 编辑自动保存，并支持撤销；应用退出后可恢复项目。
- 每个片段具有稳定 ID；改词不改变其他片段 ID。
- 修改文本、边界、旋律条件或参考音频，会将相关生成结果标记为过期。
- 旧产物可继续试听，但不能作为当前版本的有效生成结果。
- 批量任务可取消；已完成片段保留。取消后新产生的文件不自动替换当前版本。
- 标出疑似低置信度识别与重叠边界，允许人工修正。
- 原始素材保持只读；项目内保存工作副本或受控引用。

## 关键状态

素材未导入 / 分析中 / 待校对 / 可编辑 / 待生成 / 生成中 / 可试听 / 已过期 / 失败 / 已取消。

每个失败状态提供原因和对应操作：缺模型可配置路径，显存不足可释放模型并缩短片段，对齐异常可手工修正，音频解码失败可换文件。错误不覆盖已有歌词与历史生成。

## 首版验收

用 20–30 秒素材完成一次闭环：校对原词、修改一句、生成、原新切换、修改后旧版本过期、重新生成、导出。听感检查吐字、音高走势、节奏、接缝和伴奏同步。真实推理验收与界面原型验收分开。

## 原型

打开 ../design/index.html 可查看离线交互原型。支持选句、改词、演示生成、撤销当前句和进度定位。原型没有导入、真实波形、音频播放、模型推理或真实导出能力。
